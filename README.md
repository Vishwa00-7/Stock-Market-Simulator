# Stock Market Simulator

A web-based stock market simulator that allows users to view stock information and simulate buying and selling stocks.

## Features

* View stock prices and market information
* Buy and sell stocks
* Track portfolio holdings
* View available balance and portfolio value
* Simple and responsive user interface

## Technologies Used

* React
* JavaScript
* HTML
* CSS
* Vite

## Backend

This frontend communicates with a separate backend API for user, stock, and portfolio-related operations.
